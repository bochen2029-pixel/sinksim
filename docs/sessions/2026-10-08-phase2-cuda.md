Harness and model: Claude Code (Claude Fable 5.1).

## Starting point

Phases 0 and 1 done; `docs/STATUS.md` listed the Linux build, the CUDA batch driver and the ship-definition schema
as the next three things.

## What was done

1. Linux: CMake installed in WSL, the `gcc-release` preset built and tested; the oracle golden passed exactly there
   too (glibc's `pow` agreed with the UCRT on every input of the 1912 run).
2. Portable numerics: fdlibm's `sin`, `cos`, `pow` and `scalbn` ported as host-and-device functions
   (`kernel/fdlibm_portable.hpp`) and held bit for bit against the vendored C build (`test_portable_math`, zero
   mismatches in 400,000 samples per function); math policies `OracleMath`, `PortableMath`, `StdMath`; the canonical
   reduction tree (`kernel/reduce.hpp`) with CPU emulation; the flow phase refactored into per-node and
   per-connection pieces with an incidence gather that preserves the oracle's summation order; `Numerics` as a
   per-simulation runtime choice with `--numerics` on every tool.
3. The portable reference trace `data/golden/titanic64/titanic.portable.trace.json` and its CTest.
4. The CUDA batch engine: `sinksim/cuda/batch.hpp` (CUDA-free API), `engine/cuda/device_step.cuh` (one block per
   simulation, warp passes, canonical trees, serial tail on thread 0), `engine/cuda/batch.cu` (device memory,
   chunked launches, traces), `sinksim_cuda_run`, the `msvc-cuda-release` preset, and two fixture tests: the GPU
   writes a trace, the CPU in portable numerics reproduces it with tolerance zero.
5. ADR 0006, DETERMINISM with the three numerics and the measured tables, STATUS, ROADMAP, ARCHITECTURE, README.

## What was measured

- Oracle check: exact on Windows and Linux. Portable check: exact on Windows and Linux. GPU vs CPU portable: exact.
- Portable vs oracle numerics: 2e-15 in pose after one step; events shift up to 11.5 s; founder 0.5 s earlier.
- Validation table under portable numerics: same verdicts and founder minutes; two afloat cases differ by 1 to 2 t
  of final water (the stop rule ends them seconds apart), the no-BR5 case founders 2.5 s earlier.
- Throughput: CPU oracle 25,000 steps/s; CPU portable (tree emulation) 12,000 steps/s; GPU double precision 51,000
  steps/s at 8 instances, 411,000 at 66, 503,000 at 264 and 1,056 (800 full sinkings per minute). Shared memory per
  block 13,288 bytes; 2,000 steps per launch; 4,000 per launch for the throughput runs.
